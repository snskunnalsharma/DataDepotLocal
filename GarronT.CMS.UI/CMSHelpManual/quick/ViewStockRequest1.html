View Stock Request

  • This screen will be used by installer to view the requested inventory details and also by manager to approve/reject the request.


Steps

  1. User will select the Request from and To date
  2. Select the requester from the drop down
  3. Select the requester name from the drop down
  4. Click on button to search the request
  5. Click on button to reset the details


  1. Search results will be displayed as follows :
    1. Request ID
    2. Request Status
    3. Requested By
    4. Requested To
    5. Requested Date
    6. Requested Time
    7. View More


Following screen will open on view more link for installer



Click on button to exit the screen


Following screen will open on view more link for manager to approve or reject the request



  1. Click on button to approve the request
  2. Click on button to reject the request
