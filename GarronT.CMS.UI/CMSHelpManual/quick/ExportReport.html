Export Report

  • This module is used to set Fields for Project Detail report as per user's requirement and to export the report accordingly.
  • Once the required fields are set and saved, user just needs to export the report.
  • User can change the fields whenever he/she wants.
  • Different users can set different fields for report and fields will be saved for each user.



Screen: Initial Screen


Steps

  1. Click on the Menu to open the above screen.
  2. Initially all fields will be blanked.
  3. Select the Project Status from project status dropdown.
  4. Select the Project Name from project dropdown.
  5. Select the Form Name from Form dropdown.
    • All fields of the selected form will appear in Source Fields section.
  1. Select the required fields for the report by dragging and dropping required fields in the Report Fields section.
  2. Select the from and to date range from calendar
  3. Select the visit status from visit status dropdown
  4. Select 'Yes' if Lat Lon required, 'No' if Lat Lon not required
  5. Select 'Yes' if media required, 'No' if not required
  6. Click on button to save the details.
  7. Click on button to export the report to excel file.
  8. Click on button to reset all fields.
