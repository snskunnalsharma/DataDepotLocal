Form Type Master

  • This master is used to add new form types.
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Form Type Landing Page.
  2. It displays list of previously added form types.
  3. Click on button to add form type.
    • Following screen will open



    • Enter the New Form Type in the Form Type field.
    • Enter the description for the form type if any.
    • Select the dependent forms.
    • Click on button to save the reason.
    • Click on button to close the form.
    • Click on button to reset all fields.

    • Following Screen will open



    • Edit the field you want to edit.
    • Click on button to save the Changes.
    • Click on button to close the form.
