Warehouse Stock Report

  • This report will display the list of inventory available in warehouse.


Screen: Initial Screen


Steps

  1. Click on the Menu to open the report.
  2. Initially all fields will be blanked.
  3. Select utility name from drop down
  4. Select project name from drop down
  5. Select the warehouse from drop down.
  6. Select the product category from  drop down.
  7. Select the product name from the drop down.
  8. Select Summary or Detail report type from the drop down.
  9. Click on button to search the details.
  10. Click on button to export the report to excel file.
  11. Click on button to reset all fields.
  12. Summary records will be displayed as below



  1. Detail Report will be displayed as below



  1. Click on icon to edit the serial number


Following screen will open


  1. Edit the serial number and click on button
  2. Click on button to cancel the process
  3. Click on icon to delete the record
