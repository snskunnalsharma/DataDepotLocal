Return Inventory

  • This screen will be used by manager and installer to return the old and new inventory.


Old Return Inventory Screen




Steps

  1. User will select the project name from the drop down
  2. User will select to whom the inventory need to be returned i.e. manager or warehouse
  3. User will then select the manager or warehouse name
  4. Select the return type as old
  5. Enter the product name to be returned
  6. Enter the quantity to be returned
  7. Click on button to add the product into the grid


  1. Click on  icon to edit the product quantity
  2. Click on icon to delete the product
  3. Click on to complete the process
  4. Click on to cancel the process



New Return Inventory Screen - By Serial Number



  1. User will select to whom the inventory need to be returned i.e. manager or warehouse
  2. User will then select the manager or warehouse name
  3. Select the return type as new
  4. Select the serial number radio button to return the inventory by its serial number
  5. Click on icon to scan the serial number of product or will enter it manually
  6. Click on button to add the serial number into the grid


  1. Click on to complete the process
  2. Click on to cancel the process


New Return Inventory Screen - By Product Name



  1. User will select to whom the inventory need to be returned i.e. manager or warehouse
  2. User will then select the manager or warehouse name
  3. Select the return type as new
  4. Select the utility type of product
  5. Click on icon to scan the product name/UPC code/barcode or enter it manually
  6. Enter the quantity to be returned
  7. Click on button to add the product into the grid



  1. Click on to complete the process
  2. Click on to cancel the process


New Return Inventory Screen - Return All



  1. User will select to whom the inventory need to be returned i.e. manager or warehouse
  2. User will then select the manager or warehouse name
  3. Select the return type as Return All to return all the new inventory of the account
  4. Click on to complete the process
  5. Click on to cancel the process
