Running Inventory

  • This screen will display the running inventory or user.


As On Date



  1. It will display the as on date count of allocated inventory, installed inventory, transferred inventory, returned inventory and balanced inventory
  2. Click on button to sign off for the day and send the inventory status to the manager



Current Date



  1. It will display the current date count of allocated inventory, installed inventory, transferred inventory, returned inventory and balanced inventory
  2. Click on button to sign off for the day and send the inventory status to the manager
