See below details information about creation of booking form on YCB me site as follows:


    • Create Booking Form on You Can Book Me site

Follow the steps:

        1. After login to You Can Book Me site click on the “edit profile” button on the particular project profile.
        2. Select “booking form” Tab and start to create Booking Form. See the screen




    • You can create your booking form as per the requirement.
    • Follow the process below
      • Add text box: Booking
      • Click on “add a question” button.
      • Following screen displayed on the screen.



    • Follow steps:
      1. Select “Start Time” from the type Drop Down List.
      2. Enter text “Booking :” in “text before” text box.
      3. Click on “Save” button.




    • Add text box: AID
      1. Click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “AID : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “AID” in the shorthand code text box.
      5. Click on “Save” button.


    • Add text box: ACCOUNT
      1. Click on “add a question” button. (See the screen)





    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “ACCOUNT : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “ACCOUNT” in the shorthand code text box.
      5. Click on “Save” button.


    • Add next text box: First Name
    • Follow Steps:
      1. Again click on “add a question” button. (See the screen)


    • Follow steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “First Name : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “FNAME” in the shorthand code text box.
      5. Click on “Save” button.


    • Add next text box: Last Name
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “Last Name : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “LNAME” in the shorthand code text box.
      5. Click on “Save” button.



    • Add next text box: Email
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “Email address” option from the type Drop Down List
      2. Enter the text “Email : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “EMAIL” in the shorthand code text box.
      5. Click on “Save” button.


    • Add next text box: Street
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “Street : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “STREET” in the shorthand code text box.
      5. Click on “Save” button.


    • Add next text box: City
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “City : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “CITY” in the shorthand code text box.
      5. Click on “Save” button.



    • Add next text box: State
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “simple one-line question” option from the type Drop Down List
      2. Enter the text “State : “ in the text before text box.
      3. Check the check box “this is a required field”.
      4. Enter the value “STATE” in the shorthand code text box.
      5. Click on “Save” button.


    • Add next text box: Phone number
      1. Again click on “add a question” button. (See the screen)



    • Follow the steps:
      1. Select “Phone number” option from the type Drop Down List
      2. Enter the text “Please enter your phone number : “ in the text before text box.
      3. Check the check box “North American number format (e.g. 123-456-7890)”.
      4. Check the check box “this is a required field”.
      5. Enter the value “PHONE” in the shorthand code text box.
      6. Click on “Save” button.

1. Messages Subtab:

    • Used for display message after booking appointment.
    • There is one Drop Down List for ‘after the booking’.
    • That contains two options
    • Display message (not choose)


    • Select “go to url” option
    • Set the Redirect url to the web site here follow the steps:
      • Select afterwards tab
      • select messages subtab
      • Select DDL” after the booking” and choose second option “go to url”
      • Enter the following URL to redirect user to our web site page in the “url” text box.
      • For Online: http://garrontprojects.com/Client/CMSTesting/Admin/Appointment/Success?AID={AID}&FName={FNAME}&LName={LNAME}&Date={START-FORMAT-yyyy-MM-dd }&Account={ACCOUNT}&Time={START-TIME}&Email={EMAIL}&City={CITY}&State={STATE}&Phone={PHONE}&Street={STREET}
