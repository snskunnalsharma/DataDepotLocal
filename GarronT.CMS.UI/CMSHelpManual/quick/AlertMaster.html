Alert Master

  • Admin can only edit the alert name from this screen which are added from backend.


Screen: Landing Page


  • On Appointment Confirmation Customer        - Customer will receive email once an installer is allocated for an appointment
  • On Day End For Submitted Records - Day end installer/auditor status will be sent to admin        
  • On Duplicate Record Submitted - New meter number or new radio number duplicate record alert to be sent to admin
  • On Installer Allocation - Email will be sent to installer and admin after allocating and deallocating records to particular installer from installer allocation page
  • On Installer ReAssigned - If any installer is reassigned from installer page, that email will be sent to both the installer.
