Notes

Notes :


  • After transferring inventory from first user to second user and receiving the inventory by second user, first user has to click on 'Auto Sync' menu in mobile application to synchronize the inventory. If the inventory is successfully received by second user, same will deducted from the first user account.
  • In case if device is switched off or crashed use the same login credentials in another mobile to synchronize the inventory
  • In case if application is reinstalled, use the same login credentials in same or another mobile to synchronize the inventory
  • If the product quantity goes below the minimum quantity defined in product master, user will get an alert notification in mobile application.
