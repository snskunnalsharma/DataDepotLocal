View Stock Request

  • This screen will display the requested inventory list


Screen: Landing Page


Steps

  1. Click on the Menu to open Landing Page.
  2. It displays all inventory request made by installer
  3. Request pending for approval will be displayed by a icon.
    • On click of edit icon following screen will open



    • Above screen will display the system generated request id, requester user name, requested to user name, requested date, device IP, GPS location and requester comments, requested product name and quantity.
    • User will view this details to either Approve or Reject the request
    • On click of button request will be approved and email notification will be sent to installer, manager and the requested user
    • On click of button request will be rejected.
    • Click on button to cancel the process.
