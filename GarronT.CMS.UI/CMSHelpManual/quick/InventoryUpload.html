Inventory Upload

  • This screen is used to add inventory in to the warehouse
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Landing Page.
  2. Download the sample file of inventory upload from 'Download Sample File' link
  3. Enter the inventory data in to the sample file
  4. Select Utility from drop down, Projects mapped to the utility will be displayed in project drop down
  5. Warehouse mapped to the project will be displayed in warehouse drop down for selection
  6. Click to select the inventory data
  7. Click on button to upload the data
  8. Added inventory will display in the grid below along with their status.



    • Click on button to save the details
    • Click on button to reset the details
