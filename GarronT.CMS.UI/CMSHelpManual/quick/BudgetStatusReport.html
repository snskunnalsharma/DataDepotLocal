Budget Status Report

  • This report displays the real-time budget status and expenditures for a selected project and time period.


Screen: Report Page


Steps

  1. Navigate to the Budget Status Report menu under reports.
  2. Select a utility name from the Select Utility drop down.
  3. Select the project name from the Select Project drop down.
  4. Select the report frequency from the Report Period drop down (Monthly, Weekly, or Daily).
  5. Specify the timeframe using the additional filters (e.g., Year, Month, Week Range, or Datepicker ranges) that dynamically toggle based on your selection.
  6. Click on the Search button to pull the report metrics.
  7. The report will load details in the table, displaying the SrNo., Service Description, Unit Cost ($), Total Count, and Total Cost ($).
  8. Summary panels below the table highlight crucial financial status figures:
    • Project Starting Budget ($): Initial funds allocated for the project.
    • Period Used Budget ($): Budget spent during the specified period.
    • Ending Project Budget Balance ($): Remaining budget left for project execution.
  9. Click on the Export button to download the displayed report as an Excel spreadsheet.
  10. Click on the Reset button to restore the filter selectors to their default values.
