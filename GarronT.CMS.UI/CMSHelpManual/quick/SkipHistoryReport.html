Skip History Report

  • This report will display all those records which are skipped by installer and revisited again
  • This form is used to maintain history of visits


Screen: Initial Screen


Steps

  1. Click on the Menu to open the above screen.
  2. Initially all fields will be blanked.
  3. Select the Project Status from project status dropdown.
  4. Select the Project Name from project dropdown.
  5. Select he installer name from the installer dropdown.
  6. Click on button to search the details.
  7. Click on button to export the report to PDF file.
  8. Click on button to reset all fields.
