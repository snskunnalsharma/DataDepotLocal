Warehouse Master

  • This master is used to add new warehouse.
  • Admin has access to this master


Screen: Landing Page


Steps

  1. Click on the Menu to open Landing Page.
  2. It displays list of previously added warehouses.
  3. Click on button to add new warehouse.
    • Following screen will open



    • Enter Warehouse Name
    • Enter Warehouse Location
    • Select Warehouse State from the drop down
    • Select Warehouse City from the drop down
    • Select Users from the drop down to map multiple users
    • Click on button to save the warehouse details.
    • Click on button to close the process.



  1. Click on button to edit corresponding warehouse.
    • Following Screen will open


    • Modify the details as required
    • Click on button to update the details.
    • Click on button to close the process.
