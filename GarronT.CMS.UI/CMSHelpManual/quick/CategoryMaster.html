Category Master

  • This master is used to add new category for the products.
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Page.
  2. It displays list of previously added categories.
  3. Click on button to add new category.
    • Following screen will open



    • Enter the category name
    • Click on button to save the category.
    • Click on button to cancel the process.


  1. Click on button to edit corresponding category.
    • Following Screen will open



    • Edit the Category Name.
    • Click on button to save the Changes.
    • Click on button to cancel the process.
