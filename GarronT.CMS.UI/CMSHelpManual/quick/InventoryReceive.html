Inventory Receive

  • This screen is used to add inventory into the warehouse one by one.
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Landing Page.
  2. Select Utility from drop down, Projects mapped to the utility will be displayed in project drop down
  3. Warehouse mapped to the project will be displayed in warehouse drop down for selection
  4. Or Enter the product barcode/part number/UPC code
  5. Enter the inventory quantity
  6. Check 'Generate Barcode' to generate barcode of the inventory
  7. Click on button to add the inventory into the warehouse
  8. Pop up will be shown to add the serial numbers

  1. If duplicate serial number is entered alert message will be shown


  1. Click on button to add the details
  2. Click on button to reset the details
    • Added inventory will display in grid below



    • Click on icon to edit the details
    • Click on icon to delete the details
    • Click on button to save the inventory.
    • Click on button to cancel the process.
