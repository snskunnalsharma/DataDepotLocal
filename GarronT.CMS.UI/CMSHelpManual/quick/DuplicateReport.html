Duplicate Report

  • This report will display duplicate records of new meter number or new meter radio number if used in particular installation form


Screen: Initial Screen


Steps

  1. Click on the Menu to open the above screen.
  2. Initially all fields will be blanked.
  3. Select the Project Status from project status dropdown.
  4. Select the Project Name from project dropdown.
  5. Select the Installer name from the installer dropdown.
  6. Select the Field name from the Field Dropdown
  7. Click on button to search the details.
  8. Click on button to export the report to excel file.
  9. Click on button to reset all fields.
