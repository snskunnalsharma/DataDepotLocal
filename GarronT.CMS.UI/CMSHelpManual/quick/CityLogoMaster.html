City Logo Master

  • This master is used to add the city logo image.
  • Admin has right to this master


Screen: Landing Page


Steps

  1. Click on the Menu to open City Logo Master Landing Page.
  2. It displays list of previously added city logos.
  3. Click on button to add new city logo.
    • Following screen will open



    • Select State from dropdown.
    • Select City from dropdown.
    • Select Customer from dropdown
    • Enter the Name for the image
    • Upload file by clicking button
    • Image size should be 150 pixels in height * 150 pixels in width
    • Click on button to upload the image.
    • Click on button to close the form.
    • This records will be used for Print ID card.
