Inventory Stock Report

  • This report will display the running inventory of installer and manager.


Screen: Initial Screen



Steps

  1. Click on the Menu to open the report.
  2. Initially all fields will be blanked.
  3. Select the project from drop down.
  4. Select the date from the calendar, by default from and to date field will display the current date
  5. Select the installer or manager name from  drop down.
  6. Select the product category from the drop down.
  7. Select the product name from the drop down.
  8. Select the report type summary or detail from the drop down
  9. Click on button to search the details.
  10. Click on button to export the report to excel file.
  11. Click on button to reset all fields.
