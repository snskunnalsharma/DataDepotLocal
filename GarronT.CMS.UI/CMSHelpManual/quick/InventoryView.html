Inventory View

  • Uploaded and manually added inventory will display in this page.
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Landing Page.
  2. It displays list of already added and uploaded inventory from web application and mobile application.
  3. Click on icon to view other details
    • Following screen will open



    • It will display the inventory details along with the system generated request ID, Upload Type i.e. Mobile, Web Manual or Web Upload, Created Date and Time, Created by user name
    • Click on button to go back to the list page
