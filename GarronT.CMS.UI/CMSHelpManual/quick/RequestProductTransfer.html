Request Product Transfer

  • This screen will be used by installer to request for new inventory to manager or other installer of same project




Steps

  1. User will select the project name from drop down
  2. User will select the request to i.e. Manager or Installer
  3. User will then select the manager or installer name
  4. Click on button to add multiple products


Following screen will open



  1. Click on to scan the product name / UPC code / barcode
  2. Click on icon to select the product
  3. Selected product will be displayed by icon
  4. Click on button once the products are selected
  5. Selected products will be displayed in  grid
  6. Enter quantity required for each product
  7. Enter comments if any
  8. Click on button to complete the request.
  9. Click on button to cancel the process


Following pop up will be displayed on click of   button.

Click on 'OK' to close the pop up.
