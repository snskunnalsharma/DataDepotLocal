Reason Master

  • This master is used to add reasons for SKIP, RTU and REOPEN options.
  • These reasons are displayed in mobile application whenever respective option is selected.
  • Reasons can be edited and deleted through this master.
  • Admin has access to this master.


Screen: Landing Page


Steps

  1. Click on the Menu to open Reason Master Landing Page.
  2. It displays list of previously added reasons along with reason types.
  3. Click on button to add new reasons.
    • Following screen will open



    • Select the Reason Type from reason type dropdown.
    • Enter the reason.
    • Click on button to save the reason.
    • After saving, reason will be added to the grid on landing page.
    • Click on button to close the form.
    • Click on button to reset all fields.


  1. Click on button to edit corresponding reason detail.
    • Following Screen will open



    • Edit the field you want to edit.
    • Click on button to save the Changes.
    • Click on button to close the form.
