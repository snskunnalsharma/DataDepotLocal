Product Movement Report

  • This report will display the product movement from one location to another location.


Screen: Initial Screen



Steps

  1. Click on the Menu to open the report.
  2. Initially all fields will be blanked.
  3. Enter the product serial number
  4. Click on button to search the details.
  5. Click on button to reset all fields.
  6. Report will be displayed in grid below


  1. Serial number column will display the product serial number
  2. Status will display the start to current status of that serial number i.e. when the product inward to warehouse, when it is released to user, when it is installed by user, etc.
  3. Location column will display the location at each status i.e Status name 'inward to warehouse' will show the warehouse name in 'Location' field
  4. Operation Date column will display the date and time when the movement has been done
  5. Latitude and Longitude will only display when the status if 'installed by user' i.e. when the installation is completed it will show the installed location latitude and longitude
  6. Account information, street name and project name will be captured from installation screen
